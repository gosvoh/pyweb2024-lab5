# pyweb2024-lab5

Лабораторная работа №5: веб-приложение на Flask со счётчиком посещений,
хранящимся в PostgreSQL. Оба сервиса поднимаются через Docker Compose.

При каждом обращении к `/` приложение записывает в таблицу `counter` строку
с меткой времени и `User-Agent` клиента, после чего возвращает общее число
записей:

```
Hello World! I have been seen 42 times.
```

## Стек

- **Flask** — веб-сервер, один маршрут `/`
- **PostgreSQL** — хранилище счётчика
- **psycopg2-binary** — драйвер БД
- **Docker Compose** — оркестрация двух сервисов

## Запуск

```bash
docker compose up --build
```

Приложение будет доступно на <http://localhost:5000>.
PostgreSQL публикуется на порту `5432`.

Остановка и полная очистка:

```bash
docker compose down
```

## Как это устроено

### Сервисы

| Сервис | Образ / сборка | Порт | Назначение |
|---|---|---|---|
| `web` | сборка из `Dockerfile` (python:3.7-alpine) | 5000 | Flask-приложение |
| `db` | `postgres:latest` | 5432 | База `counter_db` |

Сервис `web` объявляет `depends_on: db`, но Compose гарантирует только порядок
запуска, а не готовность БД принимать соединения. Поэтому в `get_hit_count()`
реализован ретрай: до 5 попыток с паузой 0.5 с при `psycopg2.OperationalError` —
это позволяет приложению пережить холодный старт Postgres.

### Схема БД

`init.sql` монтируется в `/docker-entrypoint-initdb.d/` и выполняется при первой
инициализации кластера:

```sql
CREATE TABLE counter (
    id SERIAL PRIMARY KEY,
    datetime TIMESTAMP NOT NULL,
    client_info TEXT
);
```

> Скрипты из `docker-entrypoint-initdb.d` выполняются **только** при создании
> пустого тома данных. Если схему нужно пересоздать, удалите том Postgres.

### Разработка

В `docker-compose.yml` текущий каталог смонтирован в `/code`, а `FLASK_ENV`
установлен в `development` — правки в `app.py` подхватываются без пересборки
образа.

## Структура

```
├── app.py               # Flask-приложение: маршрут / и логика счётчика
├── init.sql             # Схема таблицы counter
├── requirements.txt     # flask, psycopg2-binary
├── Dockerfile           # Образ приложения (python:3.7-alpine)
└── docker-compose.yml   # Сервисы web + db
```

## Замечания

- **Учебный проект.** Параметры подключения к БД (`host`, `database`, `user`,
  `password`) захардкожены в `app.py:8-13` и продублированы в
  `docker-compose.yml`. При смене пароля их нужно править в обоих местах —
  в реальном проекте это следовало бы вынести в переменные окружения.
- **Учётные данные в репозитории** — `user` / `password`. Годится только для
  локального запуска.
- **Python 3.7** в базовом образе снят с поддержки (EOL — июнь 2023).
  Для актуального окружения имеет смысл поднять до 3.11+; `psycopg2-binary`
  тогда соберётся без `gcc` и `postgresql-dev`, и установку пакетов
  сборки из `Dockerfile` можно убрать.
- Соединение с БД открывается и закрывается на каждый запрос — пула нет.
